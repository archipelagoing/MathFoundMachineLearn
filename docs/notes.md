# Notes

Study notes and worked examples will be collected here as the site develops.

## Suggested learning path

1. Review vectors, matrices, and systems of linear equations.
2. Study derivatives, partial derivatives, and gradients.
3. Build familiarity with probability distributions and expectation.
4. Connect these ideas through optimization and machine learning examples.
